# Pune Food Finder

A user-friendly web application designed to help people in Pune find the best local food options based on their current area, mood, and budget.

##  Features
- **Smart Filtering:** Search food by specific areas in Pune.
- **Mood-Based Suggestions:** Get recommendations tailored to how you feel.
- **Budget Friendly:** Find options that fit your pocket.

##  Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python (Flask/Django)
